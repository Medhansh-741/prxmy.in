# Hardware asset sources

- `cpu.png`: the discrete CPU illustration embedded in Prakhar’s existing [GitHub profile processor graphic](https://github.com/prx-my/prx-my/blob/main/profile-assets/stack/processor-mobile.svg), extracted without modifying its pixels. Reused at the portfolio owner’s request.
- `gpu-owasp.webp`, `gpu-sugar-labs.webp`, `gpu-ecoaudit.webp`: Prakhar’s existing approved [GPU artwork](https://github.com/prx-my/prx-my/tree/main/scripts/console/art), reused at the portfolio owner’s request. The SVG rotor masking technique is adapted from that repository’s `gpu.py`.
- `tux.svg`: [Devicon’s Linux artwork](https://github.com/devicons/devicon/blob/master/icons/linux/linux-original.svg), distributed under the included `DEVICON-LICENSE` (MIT).
- `LICENSE` and `NOTICE`: retained attribution supplied with the GitHub profile generator. These apply to adapted generator code; they are not a blanket assertion about unrelated artwork.

The motherboard, small RAM/GPU drawings, connectors, and project frames are native HTML/CSS/SVG. They do not require a 3D runtime. All content labels are ordinary readable HTML. The large GPU’s printed count and outdated PR caption are overlaid with verified counts and a contribution action; source pixels remain intact.
